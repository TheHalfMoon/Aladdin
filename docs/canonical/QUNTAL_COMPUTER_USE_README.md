# Quntal Governed Computer Use

This folder set defines the implementation-ready QUNTAL-P18 successor plan for governed computer use after the current P16/P17 sequence.

Canonical planning inputs:

- `QUNTAL_COMPUTER_USE_PLAN.md` — architecture and SG-000073..086 sequence.
- `QUNTAL_COMPUTER_USE_DONOR_MATRIX.md` — pinned UI-TARS donor classifications.
- `QUNTAL_COMPUTER_USE_DECISIONS.md` — non-negotiable authority decisions.
- `QUNTAL_COMPUTER_USE_ACCEPTANCE_MATRIX.md` — proof required before exposure.
- `QUNTAL_COMPUTER_USE_FAILURE_SEMANTICS.md` — crash, stale, retry, cancellation, and invalidation rules.
- `QUNTAL_COMPUTER_USE_RESOURCE_BOUNDS.md` — resources that must receive hard ceilings before exposure.
- `QUNTAL_COMPUTER_USE_TEST_MATRIX.md` — adversarial and qualification catalog.
- `QUNTAL_COMPUTER_USE_PROFILE_MODEL.md` — explicit tool-surface profile rules.
- `QUNTAL_COMPUTER_USE_IMPLEMENTATION_ORDER.md` — governed execution order.
- `QUNTAL_COMPUTER_USE_GOVERNANCE_NOTE.md` — relationship to P16/P17 and historical Cotra evidence.
- `QUNTAL_COMPUTER_USE_SECURITY_DENIALS.md` — intentionally denied donor/raw authority.

The plan does not itself authorize runtime authority. Each P18 implementation capability remains blocked until its specific SpecGrain is activated and qualified.
