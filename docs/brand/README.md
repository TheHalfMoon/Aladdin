# Orcel — Brand Identity v2

Orcel uses an original rounded **O** enclosing progressively nested **r / c / e** strokes with a separate **solid-white l/I bar** at the right. The O and the right-hand I/l are filled white shapes, rather than thin outlined contours. The primary palette is white (#FFFFFF) on deep ink (#080808). Optional blue (#3B82F6) and violet (#8B5CF6) are secondary, not the official monochrome master.

Reproduce the complete SVG system using scripts/sync-brand.mjs. Export PNG, ICO and the independent v2 package using scripts/render-brand.mjs and scripts/export-brand.py. Site and marketplace visual updates depend on the normal qualified workflows; the source change alone cannot claim a newly published software release.

Prior Orcel Orbital v1 brand work is historical and retained in Git, not represented as the current identity. A legacy orcel-orbit-pattern.svg path remains as a backwards-compatibility alias. Do not distribute fonts, copy third-party brand artwork or introduce paid dependencies.
