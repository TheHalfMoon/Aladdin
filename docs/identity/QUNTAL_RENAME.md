# Quntal Identity Migration

Status: ACTIVE PRODUCT IDENTITY
Effective date: 2026-10-03

Quntal is the official product and project name formerly known as Cotra.

## Canonical naming

- Product: `Quntal`
- Root package: `quntal`
- MCP package: `@quntal/mcp`
- Relay package: `@quntal/relay`
- Rust crates: `quntal-*`
- Local daemon: `quntald`
- CLI and install root: `quntal` / `%LOCALAPPDATA%\Quntal`
- Repository identity: `TheHalfMoon/Quntal`

## Historical evidence

`.specgrain/` and `docs/canonical/` intentionally retain `Cotra` where it is part of already-authored governance, evidence, PR, CI, or canonical history. Those references identify the same project before this rename and must not be rewritten as if the historical evidence had originally used the Quntal name.

The rename changes product identity only. It does not grant new filesystem, process, network, browser, UI, secret, approval, or privileged authority.
