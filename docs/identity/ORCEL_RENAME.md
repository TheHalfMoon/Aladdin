# Orcel — Canonical Product and Repository Identity

Effective: 2026-10-15

The active product and GitHub repository are named **Orcel**.
Canonical repository: https://github.com/TheHalfMoon/Orcel
Default branch: `main`
Project site target: https://thehalfmoon.github.io/Orcel/

## Scope of this rename

The maintained code, package and workspace manifests, crate and source directories, executable and daemon identifiers, environment-variable names, website navigation and static assets, tests, workflows, and current documentation use Orcel naming. The former public name was Aladdin; older project generations were known as Deskal and QDRAL.

Identity changes must not alter security authority, expand privileges, or claim existing installed state. Previously installed binaries, environment variables, credentials, device enrollment, sessions, tokens, permissions, and protected paths are **not** implicitly mapped to their newly named equivalents. Coordinate any eventual public distribution or compatibility migration separately, with release qualification and explicit upgrade instructions.

## Historical records

Earlier governance and identity records retain their original names inside the records, where changing them would falsify the historical evidence. The original Deskal and QDRAL identity decisions are preserved verbatim in `ORCEL_HISTORY_DESKAL.md` and `ORCEL_HISTORY_QDRAL.md`. Immutable SpecGrain evidence, dated authorization grants, donor notices, and provenance snapshots likewise preserve their original text.

The name Orcel is the canonical name for all new work, without rewriting what earlier releases or approvals were named.
